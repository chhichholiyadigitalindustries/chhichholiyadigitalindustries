# CDI Work Gallery Video Assets

Drop your project showcase videos in this folder:
`public/assets/videos/`

### Recommended Video Formats:
- Format: `.mp4` (H.264 / AAC) or `.webm`
- Resolution: 1080p (1920x1080) or 720p (1280x720)
- Aspect Ratio: 16:9
- Optimized for Web (Fast start / Web optimized)

### How to use your video:
1. Save your video here (for example: `brandx-demo.mp4` or `mobile-pos-walkthrough.mp4`)
2. Open `src/data/workGalleryData.js`
3. Update `videoSrc` to `"/assets/videos/brandx-demo.mp4"`
4. Set `videoType: "video"`
